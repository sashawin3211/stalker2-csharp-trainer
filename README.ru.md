# S.T.A.L.K.E.R. 2 — C# Memory Trainer 1.3

Windows Forms, C#, Steam build **25382007**. Все функции работают через чтение
и изменение памяти игры. Консоль, UE4SS, Lua, DLL-инъекции и патчи машинного
кода не используются. Файлы установленной игры не изменяются.

## Запуск

1. Распакуй `StalkerTrainer-CSharp.zip` целиком, запусти `StalkerTrainer.exe`.
   Соседние DLL и JSON должны оставаться рядом. Нужен .NET Desktop Runtime 10 x64;
   на компьютере, где собран трейнер, он уже установлен.
2. Запусти игру через Steam, загрузи сохранение и нажми **«Подключиться»**.
3. На вкладке **«Готовые функции»** нажимай нужные переключатели.
   Активный переключатель выделяется жёлтым и показывает **ВКЛ**.
4. Оставь трейнер открытым. **Ctrl+Alt+End** или кнопка **«Выключить всё»**
   отключает готовые функции и ручное удержание адресов.

Перед подключением трейнер проверяет SHA-256 EXE. При несовпадении сборки
готовые функции недоступны; ручной сканер остаётся доступен.

## Готовые функции

| Функция | Действие |
|---|---|
| Бессмертие | Включает штатный флаг неуязвимости игрока. Сценарные смерти отдельно не проверены. |
| Бесконечные патроны | Включает штатный флаг сохранения боезапаса при перезарядке. |
| Бесконечные гранаты | Восполняет количество гранат в инвентаре. Нужна хотя бы одна; минимальный удерживаемый запас — две штуки. |
| Без перезарядки | Штатный бесконечный магазин: выстрел не уменьшает число патронов в нём. |
| Без износа снаряжения | Удерживает прочность экипированного оружия, шлема и брони; отключает заклинивание и, когда параметр доступен, расход прочности на выстрел. |
| Суперточность | Обнуляет базовый разброс обычного и первого выстрела, а также радиус отдачи текущего оружия. Для включения возьми огнестрельное оружие. |
| Бесконечная выносливость | Восстанавливает выносливость до текущего максимума. |
| Без голода | Удерживает накопленный голод на нуле. |
| Без радиации | Удерживает накопленную радиацию на нуле. |
| Без кровотечения | Удерживает скорость кровотечения на нуле. |
| Без сонливости | Удерживает обычную сонливость на нуле. |
| Купоны | Отдельная строка для установки суммы 0–1 000 000; горячая клавиша Ctrl+Alt+M. |

Удержание выполняется примерно раз в 100 мс. При смене оружия параметры точности
прежнего оружия восстанавливаются, новое определяется по его идентификатору.
Во время пересчёта данных оружия игра получает время завершить его. Прочность предметов
в рюкзаке не удерживается. Защита прочности сохраняет состояние на момент
включения; уже повреждённое снаряжение автоматически не ремонтируется.

Гранаты удерживаются в инвентаре независимо от выбранного оружия. Подобранные
гранаты увеличивают удерживаемый запас; новые стопки находятся примерно за две
секунды. Перед продажей или передачей части гранат выключай функцию: она
восполняет любое уменьшение количества, пока стопка принадлежит игроку.
Переданные целиком и пустые стопки не восстанавливаются. После выключения
функции текущее количество остаётся; последующие броски снова расходуют гранаты.

При выключении или обычном закрытии трейнера восстанавливаются исходные
управляемые флаги и параметры текущего оружия, если их объекты ещё действительны.
Значения уже восстановленной выносливости и снятых отрицательных состояний
не откатываются. Аварийное завершение трейнера не выполняет восстановление.

**Перед загрузкой сохранения выключи функции, после загрузки подключись заново.**
Идентификатор персонажа, серийный номер его объекта и связи предметов проверяются
перед работой. Если персонаж сменился или структура недоступна, работа функций
останавливается. Старые адреса не записываются в нового персонажа.

На сборке 25382007 прочитано **105 000 купонов**, сумма подтверждена в игре. Поле денег находится
в данных модуля, но его поведение после перезапуска ещё не проверено.
Проверь показанную в трейнере сумму перед записью. Изменённые игровые значения
могут попасть в сохранение.

## Ручной сканер

На вкладке «Ручной поиск адресов» сохранились поиск точного числа, отсев,
разовая запись и четыре строки удержания. Для поиска введи число из игры,
нажми «Найти заново», измени его в игре, затем введи новое и нажми «Отсеять».
Повторяй до нужного числа кандидатов; единственное совпадение само по себе
не подтверждает назначение адреса.

Поддерживаются Int32, Float32, Int64, Float64 и отсев по изменению,
увеличению, уменьшению и точному совпадению. Начальный поиск неизвестного
значения не реализован. Поиск проверяет также невыровненные значения и данные
модулей. Перед поиском готовые функции и удержание выключаются.

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+M | Установить сумму купонов из поля трейнера |
| Ctrl+Alt+F1…F4 | Включить/выключить ручное удержание соответствующей строки |
| Ctrl+Alt+End | Выключить все готовые функции и ручное удержание |

Для ручных адресов проверки идентичности игровых объектов нет: перед сменой
сохранения обязательно останови удержание и найди адрес заново.

## Исходники и сборка

Нужен .NET SDK 10 на Windows с Windows Desktop targeting pack. Сторонних
NuGet-пакетов нет. `build.ps1` запускает проверки, собирает программу и два архива.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

- `TrainerFeatures.cs` — функции, удержание, восстановление модификаторов.
- `GameProfile.cs` — SHA-256 и адреса для поддерживаемой сборки Steam 25382007.
- `PlayerLocator.cs` — пул персонажей и проверка объекта через серийный номер.
- `EquipmentLocator.cs` — текущие слоты, идентификаторы предметов и прочность.
- `WeaponAccuracy.cs` — разброс и отдача конкретного оружия, восстановление значений.
- `GrenadeInventory.cs` — поиск гранат игрока, проверка владельца и восполнение стопок.
- `ModifierLocator.cs` — таблица модификаторов персонажа.
- `Native/ProcessMemory.cs` — Win32 API и проверки памяти данных.
- `Core/MemoryScanner.cs` — ручной поиск и отсев.
- `MainForm.cs` — интерфейс и горячие клавиши.

Результаты и границы проверки описаны в `VALIDATION.md`. Автоматические тесты
не изменяют память игры: используют искусственную модель и специальные тестовые процессы.
