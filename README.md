# S.T.A.L.K.E.R. 2 — C# Memory Trainer

Трейнер для Windows с русским интерфейсом, написанный на C# / Windows Forms.
Работает через чтение и изменение памяти игры.

**Поддерживаемая версия: Steam build 24963344.** Готовые функции проверяют
SHA-256 игрового EXE; другие сборки требуют обновления профиля.

## Функции

- Бессмертие, бесконечные патроны и стрельба без перезарядки.
- Бесконечные гранаты: восполнение существующего запаса, минимум две штуки.
- Сохранение прочности экипировки и отключение заклинивания.
- Суперточность: обнуление базового разброса и радиуса отдачи оружия.
- Бесконечная выносливость, отключение голода, радиации, кровотечения и сонливости.
- Изменение купонов и ручной сканер памяти с четырьмя строками удержания.

## Сборка и запуск

Нужны Windows x64 и .NET SDK 10 с поддержкой Windows Desktop. Сторонних
NuGet-пакетов нет.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт выполняет 34 автоматические проверки, собирает приложение в
`dist/StalkerTrainer/` и создаёт архивы программы и исходников.
Для запуска собранной программы нужен .NET Desktop Runtime 10 x64.

Если трейнер уже открыт, укажи отдельный каталог сборки параметром
`-OutputDirectory 'dist\releases\1.2.0\StalkerTrainer'`.

Запусти `StalkerTrainer.exe`, загрузи сохранение в игре и нажми
**«Подключиться»**. Нужные функции включаются отдельными кнопками.
**Ctrl+Alt+End** выключает всё.

Перед загрузкой другого сохранения выключай функции и затем подключайся
заново. Адрес купонов проверен в одном запуске игры: сверяй показанную сумму
перед записью. Защита прочности сохраняет текущее состояние, без ремонта.
