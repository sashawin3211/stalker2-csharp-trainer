# Проверка версии 1.2

Дата: 2026-09-08. Windows x64, .NET SDK 10.0.201, Runtime 10.0.5.

- Release-сборка без предупреждений; **34/34** автоматических теста пройдены.
- Проверены числовые форматы, сканер, частичные чтения, отмена, Win32 ABI,
  чтение/запись тестовых процессов и остановка после завершения процесса.
- Проверены восстановление исходных флагов с сохранением посторонних битов,
  пересчёт данных стрельбы, убирание оружия, отказ от записи в сменившегося персонажа,
  повреждённая хеш-таблица, износ, удалённые предметы и переиспользование адресов.
- Для точности проверены восстановление новых значений после пересчёта,
  ожидание неготового кэша, отказ от записи при некорректном радиусе и отказ
  от восстановления параметров уничтоженного предмета.
- Интерфейс отрисован в PNG и визуально проверен.
- Гранаты: проверены восполнение, подбор, остановка, минимальный запас,
  отсев чужих предметов и других расходников, повторная проверка владельца
  перед записью, пустые стопки, переиспользование идентификатора, цепочка
  блоков пула и смена персонажа.

## Основания для адресов

- Handle игрока: RVA `0x9EDD140`; пул: RVA `0xA3237F0`, блоки по 1024,
  шаг записи `0x700`, заголовок блока `0x10`.
- Флаги игрока: `+0x13C`. Enum EGodModType: неуязвимость `1`, бесконечный
  магазин `4`, боезапас `8`, UnbreakableWeapon `16`. Запись штатного полного
  набора `0x1D` видна в реализации отладочного интерфейса EXE.
- Выносливость/максимум: `+0x150/+0x154`, кровотечение `+0x158`,
  радиация `+0x16C`, голод `+0x17C`, сонливость `+0x184`.
- Таблица модификаторов: указатель `player+0x668`; поиск по хеш-цепочке
  повторяет метод RVA `0x6AE3B2`. Для износа на выстрел используется EEffectType `0x7E`.
- Точность: `weaponModel+0x90` указывает на лениво пересчитываемый кэш;
  его полезные данные начинаются с `+8` (метод RVA `0x1EEDAC`).
  В них `+0x1F0/+0x1F4` — базовые радиусы обычного/первого выстрела,
  `+0x280` — радиус отдачи. Их использование подтверждено методом RVA `0x6BB99A`,
  отдача камеры — вызовом с типом `1` в RVA `0xFE029C`.
  Пишутся только данные конкретного оружия игрока, общие прототипы не меняются.
- Оружие/экипировка: указатель `player+0x678`; handle в руках `+0x110`,
  основные слоты `+0x1F0/+0x208/+0x220`, шлем `+0x250`, броня `+0x268`.
- Пул предметов RVA `0xA774850`, блоки по 4096, шаг `0x88`.
  Handle сверяется с предметом, модель сверяется с обратной ссылкой.
  Расположение прочности проверяется по геттеру интерфейса прочности в EXE.
- Гранаты: таблица модели RVA `0x8EA5430`; обратная ссылка `model+0x18`,
  владелец `item+0x20`, handle владельца `owner+0x68`, количество `item+0x44`.
  Списание единицы видно в `TryConsumeThrownGrenade` (RVA `0x320ED3E`),
  изменение количества — RVA `0xC7F45E`. В процессе найден `GrenadeRGD5`;
  рост запаса 3 → 4 совпал с сообщением пользователя.

В текущем процессе прочитаны оба основных оружия, пистолет, шлем и броня.
Прочность основных оружий перед тестом: 92,38% и 94,83%; остальных — 100%.
Перед исправленным тестом радиусы: АК — 148/148/270, второе оружие —
568/568/2200, пистолет — 189/189/300 (обычный/первый выстрел/отдача).

## Проверка в игре

- Версия 1.2: двухминутное удержание РГД-5 с исходным запасом **4**.
  Пользователь подтвердил, что после нескольких бросков запас восполняется
  и можно продолжать бросать. Тест завершился без ошибок; удержание остановлено.
- Купоны: последовательность 32902 → 32712, затем запись 32812.
  Пользователь подтвердил **32812** в инвентаре.
- Бесконечный магазин: флаг `0 → 4`, АК с исходными **31/52**.
  Пользователь подтвердил, что после выстрелов можно продолжать стрелять
  без перезарядки. После проверки флаг возвращён `4 → 0`.
- Совместный четырёхминутный тест: пользователь подтвердил сохранение запаса
  патронов после перезарядки и отсутствие падения прочности оружия. На каждом
  контрольном интервале защищались пять экипированных предметов.
- В том же тесте пользователь подтвердил работу защиты от урона, выносливости
  и снятия голода, радиации и кровотечения. Дополнительно сообщил, что аномалии
  перестали срабатывать. Сонливость отдельно игровым действием не проверялась.
- Первая реализация точности через таблицу характеристик не дала игрового
  эффекта и заменена работой с базовыми радиусами в данных конкретного оружия.
  В отдельном тесте исправления пользователь подтвердил более кучную стрельбу
  и отсутствие увода прицела вверх на АК с бедра и через прицел.
- Временные тесты выполняются с ограничением времени и блоком `finally`,
  который восстанавливает флаги и параметры оружия после окончания.
- После пятиминутного теста повторным чтением подтверждено восстановление
  всех трёх оружий: АК 148/148/270, второе 568/568/2200, пистолет 189/189/300.
  Тест завершился без ошибки; временные эффекты выключены.

Перезапуск игры с этим профилем и сценарные смерти отдельно не проверены.
Фиксированный RVA купонов `0x0A7FC940` подтверждён только для текущего запуска.
Новые функции определяют персонажа через handle и проверяют серийный номер
UObject, обратную ссылку и таблицу виртуальных методов.
